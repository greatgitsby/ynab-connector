# Security

The connector runs at `https://ynab.mcp.moen.ai/mcp` with read and write
access to people's YNAB plans, so security reports are welcome.

## Reporting a vulnerability

Report it privately through
[GitHub's private vulnerability reporting](https://github.com/greatgitsby/ynab-connector/security/advisories/new).
Please don't open a public issue. Include what an attacker could do and how
to reproduce it.

Only the deployed connector and this repository are in scope. YNAB's own
API and apps are not; report those to YNAB.
